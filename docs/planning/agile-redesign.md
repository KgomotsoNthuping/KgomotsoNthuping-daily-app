Iteration 1 — Application Tracking

Goal: Allow a user to track a job application through its basic stages.

Features:
- Create a job application card.
- Display the job title and company.
- Test the functionality during development.

At the end of the iteration, the working version will be reviewed and feedback will be gathered.

Iteration 2 — Application Details

Goal: Improve the usefulness of each job application card based on feedback from Iteration 1.

Features:
- Add closing dates.
- Add application dates.
- Delete job applications.
- Add simple filtering.
