## Product Backlog

## Epic 1 — Board and Stage Management
### 01 — Create a job-search board
Allow the user to create a board that represents a job-search campaign or category.

### 02 — Add default application stages
Create default stages such as Saved, Applied and Closed when a new board is created.

### 03 — Rename a board
Allow the user to change the name of an existing job-search board.

## Epic 2 — Application Card Management
### 04 — Create a job application card
Allow the user to create a card for a job opportunity.

### 05 — Edit a job application card
Allow existing card information to be changed.

### 06 — Delete a job application card
Allow the user to remove an application that is no longer needed.

### 07 — Move an application between stages
Allow application cards to move from one stage to another as the application progresses.

## Epic 4 — Search and Filtering
### 08 — Search applications
Allow users to search for applications using information such as job title or company.

### 09 — Filter applications
Allow applications to be filtered according to stage or employer.

## Epic 5 — Data Persistence
### 10 — Save application data
Ensure board, stage and application information can be stored.

### 11 — Reload saved application data
Restore previously saved information when the application is opened again.
